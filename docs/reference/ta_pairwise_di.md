# Calculate Pairwise Diagnosability Index (DI) between two species character profiles

Calculate Pairwise Diagnosability Index (DI) between two species
character profiles

## Usage

``` r
ta_pairwise_di(chars1, chars2)
```

## Arguments

- chars1:

  Named list of character states for species 1.

- chars2:

  Named list of character states for species 2.

## Value

A list containing the DI score and differentiating characters.
