# Generate a contrast table comparing character states between two taxon treatments

Generate a contrast table comparing character states between two taxon
treatments

## Usage

``` r
ta_contrast_table(text1, text2, name1 = "Species A", name2 = "Species B")
```

## Arguments

- text1:

  Character string for species 1 description.

- text2:

  Character string for species 2 description.

- name1:

  Character. Name of species 1 (default 'Species A').

- name2:

  Character. Name of species 2 (default 'Species B').

## Value

A data frame contrast table.
