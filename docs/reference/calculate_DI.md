# Calculate Pairwise Diagnosability Index

Calculate Pairwise Diagnosability Index

## Usage

``` r
calculate_DI(taxon_a, taxon_b)
```

## Arguments

- taxon_a:

  Character or numeric vector of character states for taxon A

- taxon_b:

  Character or numeric vector of character states for taxon B

## Value

A numeric value representing the Diagnosability Index (0 = identical, 1
= fully disjoint)
