# Extract characters from taxon description text with expanded ontology

Extract characters from taxon description text with expanded ontology

Extract discrete character states from treatment text based on ontology

## Usage

``` r
ta_extract_characters(text)

ta_extract_characters(text)
```

## Arguments

- text:

  Character string of the treatment description.

## Value

A list of character categories and extracted states.

A named list of detected character states.
