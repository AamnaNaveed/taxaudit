# Generate Automated Taxonomic Audit Report

Generates automated taxonomic ambiguity reports for floristic datasets.

## Usage

``` r
ta_generate_report(flora_list, output_dir = "inst/output")
```

## Arguments

- flora_list:

  Named list of taxon descriptions.

- output_dir:

  Directory path to save output reports and data.

## Value

Invisibly returns a list containing audit summary statistics and
results.
